# Прогноз успешности команд NHL

**Автор:** Абайдуллин Айдар Альбертович  
**Дата сбора данных:** 7 октября 2026 года  
**Дата завершения:** 11 октября 2026 года

Отборочное задание на прогноз успешности команды в следующем сезоне. Успешность означает, что доля побед команды строго выше медианы всех команд этого следующего сезона.

Собрано 582 записи с 24 страниц сайта. После соединения соседних сезонов получено 516 примеров. Данные разделены по году предсказываемого сезона: train — до 2005 включительно, validation — 2006–2008, test — 2009–2011.

Выбрана логистическая регрессия с признаками `win_rate` и `goal_diff`. На test получены ROC-AUC **0.760**, F1 **0.706** и accuracy **0.663**. Для F1 и accuracy использован порог 0.5.
